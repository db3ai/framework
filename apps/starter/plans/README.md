# Application plans

Optional proposals for human and agent discussion. Mark each Draft, Exploring
or Parked. Checking one in does not commit us to implementation or establish
a supported API, current behavior, reliability guarantee or authorization.

Revise or delete plans freely; Git preserves checked-in history. After delivery,
keep verified usage in the owning README and delete completed planning sections.
Builds and tests must not depend on drafts. This README is the only planning
file shipped with the starter; each generated app begins with its own empty
planning workspace.
